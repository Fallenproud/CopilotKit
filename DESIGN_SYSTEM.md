# VIBELAB Design System Documentation

## Design Tokens
Design tokens are the visual design atoms of the product that can be used to ensure a consistent design system across UI components. They include measurements, colors, typography, spacing, etc.

### Colors
- **Primary Color**: #0052CC
- **Secondary Color**: #172B4D
- **Background Color**: #F4F5F7
- **Text Color**: #172B4D

### Typography
- **Font Family**: 'Helvetica Neue', Arial, sans-serif
- **Base Font Size**: 16px
- **Heading 1**: 32px, Bold
- **Heading 2**: 24px, Semi-Bold
- **Body Text**: 16px, Regular

### Spacing
- **Small Spacing**: 8px
- **Medium Spacing**: 16px
- **Large Spacing**: 24px

## Component Library
A collection of reusable UI components that align with our design principles and adhere to accessibility standards.

### Buttons
- **Primary Button**: Filled, Rounded Corners, with a shadow.
- **Secondary Button**: Outlined, Square Corners.

### Forms
- **Input Fields**: Standard height of 40px, with a focus on accessibility.
- **Checkboxes and Radio Buttons**: Custom styling to fit the design system.

## UI Patterns
Commonly used patterns for standard functionalities:

### Navigation
- **Top Navigation Bar**: Horizontal menu that is responsive and collapses on mobile.
- **Breadcrumbs**: Used for displaying the current path in the site hierarchy.

### Modals
- **Information Modal**: Used to display informative messages to the user.
- **Confirmation Modal**: For actions that require user confirmation.
